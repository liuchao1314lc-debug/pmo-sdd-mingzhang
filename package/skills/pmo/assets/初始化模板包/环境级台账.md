# 环境级供给台账

> 落位：绑定事实登记的环境级目录（跨项目共用，不成项目私有事实，不回流进 skill）。结构与写权威按通则卷 #16；扫一次登记一次验证一次，后续项目对台账不重扫环境。

## 写权威（字段级双通道，#16）
- agent 通道：登记（核实状态＝声称有）、验证证据追加。
- 用户通道：核实授予（升"已验证"）、标已替换、新词准入、词条修订——经 #7 裁定写入；授予字段写保护，agent 不自我授予。
- 证据口径：验证证据按决-01（正式保存＋独立读回）；"已复用"必须"已验证"（#17），声称有不算。
