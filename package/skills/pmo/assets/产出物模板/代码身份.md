# 代码身份模板（版-02 三件套 · 身份 metadata）

> 用法：代码文件内以注释承载（HTML 用 `<!-- -->`，其他语言用对应注释符），唯一位置＝代码文件头部；状态板誊录指向此处。身份直接核对 metadata，不从旧聊天复制（版-02）。逻辑分区锚组件码，供沿 ID 链双向追溯（#1）。无 clean commit 时可用包快照记录当前包内容，标记未准入并如实记录缺失；是否按降级路径继续依既有纪律处理（版-06 补注）。

```html
<!-- 代码身份（版-02）
唯一位置：deliverables/〈文件名〉
版本标识：〈交付物版本；产品发布号若已发布按 SemVer（#4），与交付物版本分轨〉
来源提交：〈commit；无版本管理时按项目裁定口径注记，不冒充〉
生成时间：〈系统时钟（信-03）〉
完整性校验：〈校验和＋快照指针（执行回执／缺陷清单）〉
准入标记（版-06）：〈未准入／已准入＋依据；未 clean commit、未独立复审只能标未准入〉
上游引用：〈组件文档 D-ID＋版本；沿链需求 ID〉
修复授权：〈DR 指针（如有）〉
-->

<!-- 逻辑分区：CP-〈序号〉〈组件名〉（锚组件文档，回溯/贯穿定位用） -->
```
