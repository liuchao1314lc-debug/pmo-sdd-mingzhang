# OO 方法指引（可选）

> 约束包内可选方法资产：OO（面向对象）是 SDD 十阶段各阶段产出方法槽位的可选填充，不是新阶段、不是新门禁、**不进出口判据**。相关卡动作处放可选指针；采用与否按本指引触发条件判断，不采用无需例外审批。
> 疏为主、堵兜底：本指引疏通"同一业务概念跨阶段语义连续"；既有 ID 链／出处链／覆盖／术语表纪律照旧兜底，不新增机制。

## 一、定位与承诺边界

- OO 管"分析/设计时用什么方法把业务概念做稳"；SDD 主线管"怎么产生、放在哪、谁签字、怎么追溯"。两者不互相替代。
- 承诺＝**概念和规则可追溯**；模型允许拆分/合并/演进，不承诺对象与需求/功能/组件 1:1 不变（干跑实证：F-02 计时控制由 U-01＋U-02 双承接）。
- 借鉴边界：Meyer 无缝性（seamlessness）只借"跨阶段语义连续"一面；其"统一记法与工具"主张不采纳——记法封闭集（通则卷 #10）与图类纪律不动。

## 二、采用触发（有条件推荐）

**触发条件**：同一业务概念横跨多个功能，且具有生命周期／状态所有权／必须保持的规则。满足时在相关范围推荐采用：

- **OOA**（面向对象分析）：识别业务对象、状态、行为、关系——MRD/PRD 阶段可用。
- **OOD**（面向对象设计）：职责分配、类/接口封装——架构/模块/组件阶段可用。
- **OOP**（面向对象实现）：随架构与技术栈选择，本指引不强制——语言/范式属产品内容层。

**表达纪律**：

- MRD 随分析成果说明采用理由；需求确认和方法选择分别表达，方法选择不混入需求裁定面。
- 难改架构承诺（范式/框架级选型等）走现有架构裁定（流程卷 架构卡裁定点），不在本指引私定。
- 不满足触发条件或不采用：无需例外审批，照常走 SDD 既有方法。

## 三、图与记法边界

- 节点类型与记法封闭集（通则卷 #10）不变；不为 OO 新增图类或结构符。
- 图管定位/承接/结构覆盖；对象语义走节点描述与阶段文档（#10 文字管语义）。
- 交接与门禁输入＝图＋各卡文档与证据，不是"只看图纸"。

## 四、追溯复用（不新建机制）

同一业务概念跨阶段连续，复用既有追溯骨架：

| 追溯要素 | 既有载体 |
|---|---|
| 规范名与定义 | 术语表（通则卷 #2），同义词映射 |
| 状态/职责/接口/约束 | 对应阶段文档定义（PRD 行为描述／架构职责／模块接口／组件接口面），不另立权威 |
| 承接关系 | 出处链（#12／#10 出处语法）记录 |
| 需求身份 | 需求 ID（#1）保持；同名助对齐、非身份保证 |
| 执法 | #20 照核出处/层级/覆盖，不因 OO 增减判据 |

## 六、首版示例：专注段暂停/继续（一条真实规则做透）

教学示例，源自干跑样例（干跑-番茄钟沙盒；下列证据指针为该沙盒内位置）。四层分开，不互相混用：

1. **业务要求**（PRD）：「继续从停住处走」（PRD:52）＋计时精度 ≤1秒/分钟（PRD:46）。
2. **组件职责**（组件文档）：**计时状态和剩余时间由 CP-03 维护**（组件文档:34-38）；当前段和段参数归 CP-04（:40-44）；CP-01 读取并显示、CP-02 转发操作（:22-32）。接口行为写可观察契约：「继续时沿用暂停时的计时进度，反复暂停、继续仍须满足累计误差上限」。
3. **实现做法**（代码，实现选择非强制）：保留未取整剩余量（pomodoro.html:89），取整收口在显示边界（:87）。
4. **测试证据**（外部可测）：T-5b 非整秒最坏情形累计误差（测试报告:110-118）；DF-01 为实现偏差（DR-013 归因裁定）；v1.1 复测达标（测试报告:59）。

**教益**：明确了谁管状态之后，还要写清状态在操作前后必须保留什么——保留条件用可观察契约写，实现自选做法，测试外部验证。

**假想扩展标注**：记录与统计若提及，标假想扩展——干跑 MRD:54 deferred 未赋 ID，不入需求链。
