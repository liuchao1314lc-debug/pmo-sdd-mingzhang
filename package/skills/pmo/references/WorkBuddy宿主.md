# WorkBuddy 宿主绑定

通过 WorkBuddy 桌面端「专家·技能·连接器 → 技能 → 添加技能 → 上传技能」导入 PMO ZIP。在本地任务中选择产品项目根目录并调用 `pmo-workbuddy`。卷册、OO 指引和模板从已安装技能目录定位，状态板和交付物从本次选定的项目目录定位。

启动卡核对「已安装」中可见「PMO 项目治理」，加载后能读取同一份安装副本的卷册、模板、OO 指引和流程卷中的引用。部署回执登记 WorkBuddy 版本、技能包版本、实际技能目录、来源提交或快照和文件核验结果。每个项目按自己的状态板及授予记录推进。

按 [通则卷 #20／#21](通则卷.md) 核对状态板续接、写入边界、产出物头部、图出处及覆盖、生效记录和裁定写入通道。回执按实际登记宿主具备的执法和手工替代，涉及承重执法的降级按 #7 显式裁定。安排独立检查者时核实会话及可用工具均无项目写入权，或由独立人工承担；只交待核产物、适用判据和所需上游证据。
