# DSH 宿主绑定

DeepSeek Harness 通过 profile 安装 `dsh-plugin-pmo`。在目标项目的 DSH 会话输入 `/pmo-dsh` 加本次动作，或由 agent 通过 `skill` 工具加载 `pmo-dsh`。技能工具返回的资源目录用于定位卷册、OO 指引和模板；项目状态板与交付物从用户指定的项目根目录定位。

启动卡核对插件在所用 profile 启用、`pmo-dsh` 可加载，且该副本包含 OO 指引、流程卷动作指针可读。部署回执登记 profile、DSH 版本、插件包版本、实际技能资源目录、包来源提交或快照及核验结果。profile 可供多个项目使用，各项目按自己的状态板和授予记录推进。

插件提供 PMO 技能。按 [通则卷 #20／#21](通则卷.md) 核对状态板续接、写入边界、产出物头部、图出处及覆盖、生效记录和裁定写入通道。回执按实际登记宿主已具备的执法及手工替代，涉及承重执法的降级按 #7 显式裁定。

检查者另开只读会话或由独立人工承担，只接收待核产物、对应判据和必要上游证据。安排时确认会话和可用工具均无项目写入权，检查结论交用户裁定。
