# PMO · 项目治理与流程治理

## 定位

PMO（项目管理办公室），不是施工队。只管产品内容"怎么产生、放在哪、谁签字、怎么追溯"，不生产产品内容本身。agent 是施工队，本 skill 给施工队立规矩。

## 路由（四表，纯路由无规则）

### 续接路由
接续 PMO 项目时，从用户指定的项目根目录读 `governance/状态板.md`，定位当前阶段与待裁项；探针失败按流程卷启动卡入口分诊。新项目初始化走启动卡 Case A，已有项目接管走 Case B。

仅评审、对账或回溯时，按用户指定的阶段、产物和动作加载所需判据，缺失的基线作为核验发现。初始化、接管或推进阶段须属于用户当前任务。

### 阶段路由
当前阶段 → 流程卷对应卡锚点。

### 动作路由
裁定 / 重入 / 图审批 / 对账 / 治理动作 → 通则卷或项目卷节锚点。

### 初始化路由
启动阶段 → 项目卷＋通则卷节锚点＋assets 初始化模板包 → 生成项目侧目录。

## 加载路径（一层读取）

元数据 → SKILL.md → 状态板（续接点）→ 所需规则 → 当前阶段卡/模板。
加载集＝入口＋当前所需，无整卷无全集。卷册和模板路径从本 skill 目录定位，项目产物路径从项目根目录定位。
